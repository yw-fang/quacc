# Minimal QE 7.5 Pb EPC fixtures

`pb_dfpt/` contains a complete one-atom fcc Pb DFPT/EPC source: four irreducible
q-points of a 3×3×3 grid and two broadenings (0.0025 and 0.005 Ry). Its 17 files
occupy about 5.2 KB compressed. The native test runs only q2r and matdyn; it needs
no pseudopotential, SCF, wavefunctions or DFPT execution. gzip mtimes are zero.

Generation follows the [ICTP Pb tutorial](https://indico.ictp.it/event/8301/session/96/contribution/534/material/0/0.pdf):
scalar-relativistic `pb_s.UPF` (PZ), fixed a=9.2225583816 bohr, 30/120 Ry cutoffs,
18³ fine and 9³ coarse unshifted electronic grids, cold smearing 0.05 Ry,
SCF tolerance 1e-10 and DFPT tolerance 1e-12. SOC is omitted. These settings are
for a small software regression, **not a converged superconductivity benchmark**.
Full-precision 0.0025 Ry prints as 0.003 Ry in the log, exercising the rounding bug.

`a2F.dos1.gz` is one complete 120-bin spectrum generated by matdyn on an 8³ grid.
All three mode columns and signed rows are retained. `expected.json` records the
independently executed hyllios/utils AllenDynes class at three mu-star values.
The 2e-7 relative tolerance is a same-algorithm regression lock, not an accuracy
bound on quadrature, convergence or Tc. The formulas use positive-frequency
Simpson integration. QE's footer instead uses all bin-centred signed rows and
its exact Delta; the independent midpoint anchor agrees within 1e-3.

The Simpson result, QE midpoint footer and QE q-sum need not coincide, especially
for coarse interpolation and low-frequency weight. Tests compare the correct
methods and retain their differences instead of forcing agreement or changing
spectra. Large lambda is retained with a formula-regime warning.

`matdyn.freq` contains two native q-point blocks with `nks` adjusted to 2.
`matdyn.dos` contains its header and three rows, **not a normalized full DOS**.
`lambda.gz` preserves the two native auxiliary rows. `provenance.json` records
settings, the potential hash, the reference revision and uncompressed source
hashes. The potential and full electronic calculation data are not bundled.

Small synthetic tables in the tests exercise missing/malformed/ambiguous data,
wrong file identities, units, signed moments, independent formula domains and
numerical limits. Mocked flow tests check customization and backward compatibility;
the separate native test verifies the actual QE file-transfer and executable path.
